添加路由

正向代理：把本机这个端口当作 HTTP/HTTPS 代理，转发到上游代理（Mihomo/Clash）。 用法：在浏览器或工具里把代理设为 http://127.0.0.1:<端口>。 注意：HTTP 站点可正常代理；HTTPS 站点依赖 CONNECT 隧道，若上游网关（如绿联 uglink 反向代理）不支持 CONNECT 字节转发，HTTPS 代理会失败。

⚠️ HTTPS 站点（CONNECT 隧道）经绿联 uglink 反向代理通常无法使用：网关在 CONNECT 握手后会断开字节流。 仅 HTTP 站点可正常代理；需要 HTTPS 请改用局域网直连或支持 TCP 转发的隧道（frp / ngrok tcp）。
